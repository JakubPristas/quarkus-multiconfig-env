# Quarkus MultiConfig Extension

Quarkus MultiConfig is an extension that allows you to automatically generate configuration files for different environments (such as development, testing, or production) based on a single input properties file.  
It simplifies the creation of Kubernetes ConfigMaps, `.env` files, and `application.properties` files during build time.

You can learn more in the [Quarkus MultiConfig Documentation](https://jakubpristas.github.io/quarkus-multiconfig/quarkus-multiconfig/dev/index.html).
